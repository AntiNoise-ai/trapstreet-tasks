# TrapStreet Tasks

Standardized eval task cases for the TrapStreet platform. Each case has well-defined input/output fields and points to a public dataset — no data is stored here.

## Cases

| # | Name | Dataset | Direction |
|---|------|---------|-----------|
| 2 | [Article Summarization](./case2_article_summarization/) | CNN/DailyMail | Practical |
| 4 | [Everyday Q&A](./case4_everyday_qa/) | TriviaQA | Practical |

## Criteria

All cases meet the original ticket requirements:

- **No-tech friendly** — concept is immediately obvious to any user
- **Universal** — no special environment or domain knowledge needed
- **Fast** — individual examples run in seconds
- **Standardized** — public datasets with existing human-labeled input/output pairs
