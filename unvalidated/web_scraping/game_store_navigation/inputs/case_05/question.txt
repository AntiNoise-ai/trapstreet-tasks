This case includes an offline copy of a small game storefront (NebulaKey Store) as static files in this same directory. Start a local web server before navigating -- fetch()-based pages (bundle tiers, the catalog) need http:// to work; opening the files directly via file:// will not work correctly:

    python3 serve.py            # serves at http://localhost:8000/index.html
    python3 serve.py 8080        # or pick a different port
