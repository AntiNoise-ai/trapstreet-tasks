# Data License & Attribution

## Content: Synthetic

Every tool schema, user query, and expected answer in this task is authored
for this task -- the eight intent families and their forty near-miss tools by
hand (`families.json`), the 338-tool filler pool by a committed generator
(`gen_filler.py` -> `filler_pool.json`). No external corpus, dataset, API
reference, or real tool catalog is used, and no real product names appear in
any schema. There is no leakage risk from model training data by construction.

The synthetic content is released as part of the trapstreet-tasks repo,
under the same license as the repo.
