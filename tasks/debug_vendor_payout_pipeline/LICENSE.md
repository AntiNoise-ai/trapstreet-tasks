# Data License & Attribution

## Content

All code, data files, and case scenarios in this task are **fully synthetic** — hand-authored specifically for this evaluation. No real customer data, no real proprietary code, no scraped external content.

The scenarios are **inspired by** common patterns in supermarket vendor-consignment and e-commerce vendor-payout pipelines:
- Multi-source data (main table + auxiliary contracts) creating consistency traps
- Per-vendor SKU naming conventions
- Effective-date-based rate routing
- Percentage vs fixed vendor-payout term transitions
- Baked vs looked-up fields diverging across reports

But no specific real system was used as a template.
