## Licence status — read this before relying on the task being public

**No redistribution licence has been established for this document.** This is
recorded plainly rather than glossed, because it is the one thing about this
task that cannot be undone later.

What was checked:

- The PDF itself carries no copyright notice, licence statement, or terms of
  use — searched for `copyright`, `©`, `licen*`, `reproduc*`, `redistribut*`,
  `all rights`.
- EPD Hub publishes no terms-of-use page that could be located; the URL that
  would conventionally hold one returns 404.
- The comparable programme operator, IBU, grants users "a simple,
  non-exclusive, non-sublicensable right to use the database content free of
  charge **for their own use**". That is an own-use licence, not a
  redistribution licence. If EPD Hub's unpublished terms resemble IBU's, this
  task exceeds them.

What that means in practice:

- Free public availability is **not** a grant of redistribution rights.
- Publishing this task distributes the PDF to everyone who runs it.
- Removing the task later does not undo that distribution.

This differs from the repo's other vendored corpora, which cleared an explicit
licence before being committed — CUAD under CC BY 4.0, and `tasks/imported/`
under the permissive-licence policy in
[`../imported/README.md`](../imported/README.md). This task does not meet that
bar and is published at the project owner's explicit direction, with the gap
recorded here.

## Cleaner replacements, if this needs to change

The task's questions are written against the standard EN 15804 table layout —
`A1`–`A5`, `B1`–`B7`, `C1`–`C4`, `D` as columns, impact categories as rows.
That layout is shared by every EPD, so the case templates transfer to any other
declaration with only the gold figures needing to be re-read. Sources with an
explicit redistribution licence would remove this problem entirely:

- an EPD programme operator that publishes under a Creative Commons licence
- UK government statistical releases under the Open Government Licence, which
  use the same wide indicator-table shape and permit redistribution outright
