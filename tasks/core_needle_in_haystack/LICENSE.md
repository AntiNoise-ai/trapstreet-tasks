## Content: Synthetic

All haystack content in this task is **synthetic** — generated by a Python builder using hand-authored templates for tech-documentation prose (Tier 1 and 2 chunks) and templated substitution for policy-style filler (Tier 3 long docs). No external corpus, book, or dataset is used.

The synthetic content is released as part of the trapstreet-tasks repo, under the same license as the repo.

## Pattern inspiration: gkamradt NIAH

The core needle-in-a-haystack pattern is inspired by:

- **gkamradt / LLMTest_NeedleInAHaystack** (MIT) — https://github.com/gkamradt/LLMTest_NeedleInAHaystack

The classic form: plant "The magic number is N" in a corpus of filler text and check whether the model retrieves N.

This task extends the pattern in two ways to test agent-realistic scenarios:

1. **Topic-distractor tier** — multiple codewords for related keys in the same domain; question asks for one specific key. Tests precision, not just recall.
2. **Long-doc precision tier** — coherent long documents (contract, handbook, spec, policy, manual) with 5 similar-format clauses. Tests retrieval under length + structural distractors.
